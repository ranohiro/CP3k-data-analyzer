仮想環境（`.venv` など）の中には、OSや環境に依存するPythonの実行ファイルや、インストールされたライブラリ本体など、大量のファイルが含まれています。これらをそのままGitで管理してしまうと、Macで作った仮想環境がWindowsで動かないなどの問題が起きるため、**Git管理から除外（`.gitignore` に記載）するのがプログラミングの基本かつベストプラクティス**となっています。

そのため、通常はライブラリのリストだけを `requirements.txt` というテキストファイルでGit管理し、各開発者が自分のPC上で新しく仮想環境を作成してリストからインストールする、という運用を行います。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
