# CP3k Data Analyzer

## プロジェクトの目的
本プロジェクトは、臨床検査薬メーカーの研究開発員向けに開発された、自動生化学分析装置（例：CP3000等）から出力されるCSVデータを解析するためのStreamlitベースのGUIアプリケーションです。

試薬開発や装置パラメーター検討におけるデータ解析の課題を解決するため、以下の機能を提供します。

### 主な機能
1. **CSVデータの可読性改善:** 複雑なCSVデータを読み込み、上段・下段データを自動分離して整理された内部データ（DataFrame）へと整形します。
2. **吸光度プロファイルの可視化:** タイムコースデータ（時間経過に伴う吸光度変化）をグラフとして展開・表示します。
3. **検量線の構築と可視化:** キャリブレーションデータを抽出し、折れ線（Piecewise Linear）やスプライン（Cubic Spline）などの手法による検量線を生成します。
4. **任意区間選択による再計算:** タイムコースグラフ上からのポイント指定またはクリック選択により、任意の2点間における傾き（処理値）を再計算します。
5. **濃度の再算出:** 再計算された処理値と構築した検量線を用いて、一般検体の濃度を再計算します。
6. **複数サンプル比較・データ処理標準化:** 検体の測定値を比較解析し、計算過程（ΔAbs, ΔTime）を表示して試薬開発へのフィードバックを支援します。

## ディレクトリ構造

以下のツリーは本プロジェクトのディレクトリ構造を示しています。

```text
.
├── .gitignore
├── AI-chat/
│   └── Antigravity/                  # AI（Antigravity）とのチャット履歴、開発プロンプト、及び解析用生データ集
│       ├── 2406_F07/                 # 解析テスト用データ群
│       ├── タイムコース解析/         # タイムコース用生データ及び乖離検体データ群
│       └── ...
├── data/                             # データ保存用ディレクトリ
│   └── parsed-data/                  # パース済みの分析用データ（Parquet形式、JSONメタデータ）
├── main.py                           # Streamlitアプリのメイン実行ファイル（エントリポイント）
├── plan.md                           # 開発要件、機能要件、データ構造の定義などをまとめた計画書
├── requirements.txt                  # 必要なPythonパッケージ一覧
├── src/                              # ソースコード・解析用ノートブック
│   ├── 01_correlation_original.ipynb # 相関解析のオリジナルノートブック
│   ├── 01_correlation_参考.ipynb     # 相関解析の参考ノートブック群
│   ├── common/                       # アプリケーション共通のユーティリティ関数
│   │   ├── analysis_utils.py
│   │   ├── calibration_manager.py
│   │   └── csv_loader.py
│   └── タイムコース解析_test.py      # タイムコース解析のテスト・試作スクリプト
└── tools/                            # 開発補助用ツール
    ├── check_nb.py
    └── read_ipynb.py
```

## 使い方（実行方法）
1. 必要なライブラリのインストール
   ```bash
   pip install -r requirements.txt
   ```
2. アプリケーションの起動
   ```bash
   streamlit run main.py
   ```
